# Apply Tracker — tempat manage semua lamaran kerja

> Dipakai buat nyimpen satu folder per lamaran: email, cover letter, recap job description, dan status.
> File ini **catatan pribadi** (seperti `screening-answer.md`): jangan di-commit ke repo.

## Cara nambah lamaran baru
1. Copy isi folder `_template/` → buat folder baru: `apply-to/<perusahaan>-<nama-recruiter>/` (pakai huruf kecil, hubungkan pakai tanda hubung).
2. Isi `job.md` (recap JD: role, client, syarat, siapa recruiter, CV yang dipakai).
3. Tulis/ubah `email.md` dan `cover-letter.md` sesuai lowongan (arahkan ke *bisnis/outcome*, bukan cuma daftar skill).
4. Update tabel tracker di bawah: status + tanggal + CV yang dikirim.
